## 용어

- **캐시 쓰기(Cache Write)**: 반복 사용할 내용을 처음 한 번 "기억"시키는 비용. 입력 가격의 1.25배(5분 유지) 또는 2배(1시간 유지).
- **캐시 읽기(Cache Read)**: 이미 기억된 내용을 재사용하는 비용. 입력 가격의 약 0.1배로 훨씬 저렴함.
